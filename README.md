# Steam Deck Patch Path Relay Fix

This example demonstrates the 'Relay Transfer Method' for resolving Windows .exe patch path errors on Steam Deck. It simulates a Proton game installation and then creates a simplified 'relay' directory structure with a symbolic link, allowing a hypothetical Windows patch to find game files despite complex Linux paths.

## Language

`bash`

## How to Run

Save the code as `relay_patch_fix.sh`. Make it executable with `chmod +x relay_patch_fix.sh`. Run it from your terminal: `./relay_patch_fix.sh`.
